1. Introdução à Base de Dados
A solução utiliza como fonte de dados o banco HFSQL, responsável por armazenar todas as vendas realizadas no sistema de PDV. A tabela principal utilizada é a TAB_VENDA_ITEM, que contém os itens de cada venda. Cada linha representa um produto vendido dentro de uma venda específica.
Essa tabela é suficiente para gerar toda a matriz de coocorrência, pois contém:
- O ID da venda
- O ID do produto
- A descrição do produto

4. Conexão Python → HFSQL
A conexão é realizada utilizando o driver pypyodbc, que permite que o Python se conecte ao HFSQL via ODBC.
4.1. String de Conexão
conn = pypyodbc.connect(
    "Driver={HFSQL};Server Name=localhost;Server Port=4900;Database=A37278473;UID=admin;PWD=;"
)
4.2. Explicação dos Parâmetros
- Driver → Driver ODBC do HFSQL
- Server Name → Nome do servidor (localhost)
- Server Port → Porta padrão do HFSQL (4900)
- Database → Nome do banco
- UID → Usuário
- PWD → Senha

6. Consulta SQL Utilizada
SELECT 
    CAST(ven_id AS VARCHAR(50)),
    CAST(pro_id AS VARCHAR(50)),
    CAST(descricao AS VARCHAR(255))
FROM TAB_VENDA_ITEM

Por que usar CAST?
- Evita erros de tipo no Spark
- Garante consistência entre colunas
- Facilita joins e agrupamentos

8. Código Completo da Conexão e Consulta
conn = pypyodbc.connect(
    "Driver={HFSQL};Server Name=localhost;Server Port=4900;Database=A37278473;UID=admin;PWD=;"
)
cursor = conn.cursor()

cursor.execute("""
    SELECT 
        CAST(ven_id AS VARCHAR(50)),
        CAST(pro_id AS VARCHAR(50)),
        CAST(descricao AS VARCHAR(255))
    FROM TAB_VENDA_ITEM
""")

dados = cursor.fetchall()
conn.close()
